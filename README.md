## Atelier 6 — FastAPI et Streamlit

Pour l'Atelier 6, j'ai cloné et utilisé le code FastAPI et Streamlit fourni par vous : 

https://github.com/msellamiTN/Cloudera-CDP-Training

J'ai configuré les conteneurs Docker et connecté l'application à ma propre base de données HBase (`product_analytics`), alimentée lors des ateliers précédents.

Le test a été réalisé avec succès : l'API FastAPI récupère les données de ma base HBase et le dashboard Streamlit les affiche correctement.
